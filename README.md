# Preset Weaver

一个面向 SillyTavern v1.18 的聊天补全预设管理器。这是**纯 UI 扩展版**，安装后无需 Server Plugin。

## 功能

- 聊天补全预设快速切换
- 多标签分类、按分类筛选、按最近使用排序
- 一键提取当前预设全部非 marker 提示词为模块
- 模块预设私有：每个预设对应自己的模块，不可共享到其他预设
- 常用标签快加（常用、角色扮演、文笔、NSFW、系统、规则、剧情、战斗）
- 悬浮窗可拖动，桌面/手机自适应
- 模块编辑、开启/关闭、分组开关
- 修改模块后选择同步到引用它的预设
- 覆盖、切换、恢复前自动备份
- 备份与插件数据导出导入
- 桌面/手机自适应悬浮窗
- 独立白天/夜间模式

## 一键安装

1. 打开 SillyTavern。
2. 进入 **Manage Extensions**。
3. 选择从 GitHub URL 安装扩展。
4. 填入：

   ```text
   https://github.com/wzkdsb66/st-preset-weaver
   ```

5. 安装完成后刷新页面，点击右侧悬浮按钮 🧵 开始使用。

## 数据位置

模块库、分组、使用记录和备份保存在当前浏览器可访问的 SillyTavern 本地存储中：

- 使用 `IndexedDB` / `localforage` 保存大块数据；
- 使用扩展设置保存一个匿名存储键。

不需要修改 `config.yaml`，不需要安装 Server Plugin，也不会上传数据。

跨设备迁移时，请在插件设置里使用 **导出全部数据** 和 **导入**。

## 验收

建议在真实 SillyTavern v1.18 中验证：扩展安装加载、预设切换、模块提取与开关、分组控制、备份恢复、导入导出、双端 UI、主题切换。纯 UI 版数据保存在浏览器中，不同浏览器不会自动共享数据。
